# Исправления интерфейса в ветке fixes

Проверка выполнена 15 ноября 2026 года на актуальном main после PR №13. Изменения относятся к frontend; Go API и ML не изменялись.

## Вес и тренировочный объём

Отрицательное значение в карточке прогресса было дельтой между измерениями, а не отрицательным весом тела. Двоичная арифметика также выводила лишние знаки: `-1.2000000000000028`. Общий форматтер теперь показывает `1,2 кг` и отдельное направление «Вес снизился». Малые изменения, округляющиеся до нуля, показываются как отсутствие изменения. Одинаковое представление используется в обоих интерфейсах прогресса. Форма записи веса сохраняет ограничения 1–500 кг; браузерный тест проверяет, что отрицательное значение не отправляется в API.

Объём 8 775 кг в демо подтверждён исходными подходами: это сумма веса, умноженного на повторения, во всех рабочих подходах шести занятий. На главной показаны последние 28 дней; в прогрессе — выбранная неделя, месяц или всё время. Значение не ограничивается искусственно. Добавлены название периода, даты из серверного часового пояса, средний объём за занятие и раскрываемое объяснение формулы. Объём отдельной тренировки подписывается отдельно. Разминка исключена; подходы без дополнительного веса дают нулевой объём.

Личные рекорды сгруппированы по упражнению с его названием и ссылкой на историю. Из нескольких улучшений одного показателя остаётся лучший результат. Отсутствие запланированных занятий в периоде поясняется отдельно от нулевого выполнения существующего расписания.

## Вёрстка

Общая оболочка получила единые размеры полей и кнопок, переносы действий заголовка и адаптивные сетки. Кнопки поиска выровнены по нижней границе поля. Fieldset и элементы сеток могут сжиматься на узком экране. На телефоне пять основных разделов видны сразу; остальные находятся в раскрываемом меню «Все разделы». Меню закрывается после успешной навигации и сохраняется при отмене выхода из несохранённого редактора.

Упорядочены отступы, карточки каталога, блоки главной и статистика. Сохранены палитра, шрифт, архитектура и оба семейства экранов после объединения PR. Проверены светлая и тёмная темы, в том числе нативные поля даты. Визуально проверены ширины 320, 390, 681 и 1280 px.

## Проверки

- Node 24: `npm run verify` — lint, unit/component и Node contract tests, production build.
- Playwright с контрактными фикстурами — 52 успешных проверки на desktop и mobile. Включены регрессии дельты веса, запрета отрицательной записи, переполнения на 320 px, навигации с подтверждением выхода и выравнивания поиска.
- Go 1.25.5: `make -C backend verify` и полный `go test ./... -count=1` на новой отдельной PostgreSQL 18.
- Production frontend с настоящим Go API — 18 успешных браузерных проверок. Postman/Newman — 154 запроса, 716 утверждений, без ошибок.
- Независимое read-only ревью diff и целевых тестов — замечаний нет.

Браузерные mobile-проверки используют эмуляцию Chromium, а не физическое устройство. Интеграции используют синтетические данные отдельной тестовой БД и контрактную ML-фикстуру. Это не проверка реального платёжного провайдера или ML-модели. Финальное изменение `color-scheme` дополнительно проверено визуально в тёмной теме; после него повторены frontend verify и целевые браузерные регрессии.
