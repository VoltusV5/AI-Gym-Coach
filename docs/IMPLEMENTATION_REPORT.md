## Подтверждённые проверки

- `GOTOOLCHAIN=go1.25.5 make -C backend check`: форматирование, vet, тесты без внешних сервисов, сборка, golangci-lint 2.10.1.
- Полная Go-интеграция на новой синтетической PostgreSQL18,127.0.0.1:55443. Базовые миграции 1–9 применены; для 10–19 проверен up/down/up; populated откаты commerce и сохранение legacy-профиля/заметок/программы проверены отдельно.
- PostgreSQL-интеграция проверяет авторизацию/владельцев/блокировки, версии, конкурентные повторы, генерацию/недоступность ML, денежные суммы, HMAC и replay webhook, возвраты, выплаты и paid_at, provenance, лицензии, отозванные ссылки, отзывы, жалобы, подписки, outbox, события, справочники и аналитику. Добавленные регрессии проверяют фильтр частоты, версию фактических занятий для отзыва, запрет unsafe генерации и реальные SQL-отказы отдельных блоков dashboard. Seed-регрессия проверяет rename/media/equipment после рестарта; отдельный red/green-тест воспроизводит и устраняет конкурентное восстановление удалённого оборудования.
- Frontend: линтеры,17 unit/component тестов и production build. В числе регрессий — смена аккаунта в открытом редакторе и независимость черновиков разных планов.
- Playwright в установленном Chrome:18 сценариев на desktop/mobile с управляемыми API-ошибками;18 сценариев с настоящим Go API на изолированной БД. Проверены регистрация/вход, каталог, избранное, план, две тренировки подряд, прогресс, рекомендации, sandbox-покупка/Fork/возврат, восстановление pending при 404 плана, относительные mediaURL, модерация, видимая ошибка анкеты/повтор, анкета→AI-генерация→редактор→сохранение→reload и 3 занятия→отзыв→удаление.

## Границы результата

Старый экран JSON-программы сохранён по `/previous-plan`; автоматического переноса неизвестного legacy JSON в v2 нет. Платёжный оператор и выплаты являются явной заглушкой. Вывод комиссии платформы, частичные возвраты, внешние push/email и ML-реализация ranking/explain не подключены. Go использует фактический fallback и шаблонные объяснения; AI-сообщение главной также шаблонное. Лицензия ранее созданного Fork после возврата требует отдельного решения до настоящих продаж.

Проверены web production build, desktop Chrome и mobile Chrome с iPhone-размером. В репозитории нет native Android/iOS-проектов и соответствующей SDK/signing-конфигурации; APK/IPA и физические устройства не проверялись. Это не следует представлять как успешную native-сборку. Dockerfile builder согласован с Node 22, но Docker image build не запускался: Docker daemon в окружении недоступен. В Vite остаётся предупреждение о размере основного Ionic/Vue chunk.

Подробные технические решения подготовлены для отдельной передачи команде в `TEAM_IMPLEMENTATION_NOTES.md`; файл намеренно игнорируется Git.
