# Интеграция с API Спортика

1. Сверь развернутый контракт Go и OpenAPI. Определи версию API, тело, права гостя и зарегистрированного пользователя, обязательные заголовки, ошибки и форму страниц. Не используй проектируемый маршрут как реализованный.
2. Переиспользуй api из src/api/api.js и v2 из src/api/v2.js. Документируй DTO и поведение в JSDoc. Не передавай JWT в параметры URL и не выводи сырой Axios error.
3. Для списка используй usePages, сбрасывай курсор при смене фильтра и избегай дублей. Для чтения через useRead передавай signal. Для записи используй useWrite, показывай исход и сохраняй черновик при сбое. При 409 запроси последнюю версию для явного повторного сохранения. Идемпотентный повтор отправляет тот же ключ и то же тело.
4. Проверь штатный ответ, отказ доступа и сетевую ошибку с контрактными фикстурами. Браузерный прогон с Go выполняй на отдельной БД. Запусти npm run verify и передай diff на отдельное ревью.

В src/views/v2/MarketplacePage.vue состояние фильтров хранится в URL, а usePages добавляет курсор к тем же фильтрам:

```js
const programs = usePages((cursor, signal) => v2('GET', '/catalog/programs', {
  params: { ...filters.value, price_type: 'free', cursor },
  signal,
  anonymous: true,
}))
```
