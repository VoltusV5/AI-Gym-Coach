# Компонент Vue и Ionic

1. Прочитай frontend/AGENTS.md, контракт задачи и нужный экран в docs/03_FRONTEND.md. Найди существующие оболочку, маршрут и компоненты перед добавлением новых.
2. Страницу оформляй через FeaturePage или существующий IonPage с IonContent. Храни локальный ввод в компоненте. Передавай данные через props, а события изменений через emits или defineModel. Общий сеанс остаётся в Pinia.
3. Обозначь поля видимыми подписями, кнопки действий — текстом. Ошибку покажи рядом с формой, прогресс и успех — через status. Проверь клавиатуру, узкий экран, пустое состояние и отсутствие повторной отправки.
4. Добавь целевой сценарий в frontend/tests/e2e, если меняется пользовательский путь. Запусти npm run verify и нужные сценарии Playwright. Передай diff на отдельное ревью согласно корневым правилам.

В src/views/v2/PlanEditPage.vue компонент DayEditor редактирует дни через v-model и сообщает об удалении дня. Владелец расписания очищает ссылку в обработчике removed-day:

```vue
<DayEditor v-model="draft.days" :exercises="exercises" @removed-day="removeScheduleDay" />
```
